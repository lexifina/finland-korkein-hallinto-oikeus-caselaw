# KHO 28.11.1973/4809

## Suomeksi

Samalla kauppakirjalla oli myyty kolme kiinteistöä kahdelle henkilölle maininnoin, että tilat A ja B sekä metsäalue tilasta C jäivät ostajien yhteisiksi, kun taas tilan C pellot oli jaettava määräaloina ostajien kesken. Ostajien hakiessa määräajassa lainhuutoa tiloihin A ja B kauppakirja oli varustettu kaikkien kiinteistöjen yhteistä arvoa vastaavin leimamerkein. Tilan C kohdalta ostajat hakivat lainhuutoa sen jälkeen kun tilasta oli kauppakirjan määräysten mukaan lohkomalla muodostettu tilat C 1, C 2 ja C 3, molemmat ostajat heille yhteisesti muodostettuun tilaan C 1, toinen ostajista hänelle muodostettuun tilaan C 2 ja toinen ostajista hänelle muodostettuun tilaan C 3. Kun omistusoikeus tilaan C oli siirtynyt ostajille kauppaa tehtäessä ja velvollisuus hakea lainhuutoa oli alkanut kaupantekopäivästä eikä lainhuutoa tämän tilan kohdalta ollut haettu lain säätämässä ajassa mainitusta päivästä lukien, leimaveroa korotettiin tilan C arvon osalta.
Vrt. KHO:1955-II-24, KHO:1963-II-178, KHO:1962-II-200.
